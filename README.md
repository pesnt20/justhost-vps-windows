## 连上远程桌面只需要四步

RDP 是 Windows 内置的协议，服务端不需要额外装任何软件，连接端也不需要。

1. 按 `Win + R`，输入 `mstsc` 回车，打开“远程桌面连接”。
2. 在“计算机”一栏填 IP。如果服务商给的端口不是默认的 3389，写成 `IP:端口`，例如 `123.456.789.0:1234`。
3. 用户名填 `Administrator`，密码用服务商发到你邮箱的初始密码。
4. 首次连接会弹出证书警告，勾选不再询问并接受，就能看到远端桌面。

Mac 没有内置 RDP 客户端，去 App Store 装微软官方的 Microsoft Remote Desktop，填法完全一样。iOS 和 Android 也有同款应用。

**RDP 默认关闭怎么开。** 有些镜像装好后远程桌面是关着的，先用控制面板里的 VNC 进系统，右键“此电脑”→ 属性 → 远程设置 → 勾选“允许远程连接到此计算机”，同时勾上“仅允许运行使用网络级别身份验证(NLA)的远程桌面连接”，再去防火墙确认 3389 端口的入站规则是放行状态。

**连不上先查三处。** IP 和端口有没有填错；防火墙有没有把 3389 挡住；VPS 本身是不是已经宕机，从控制台重启一次。都排除掉还慢，就是线路问题，换机房。JustHost 的用户中心支持自助切换机房，先挑离你近的城市试，国内用户优先看亚洲节点，具体可选城市以配置器列表为准。

## 单人用 VPS 就够，多人要换 RDS

一个人用一台 Windows，VPS 加 RDP 就是全部。要给同事开账号、几个人同时登录同一台机器干活，产品类型就变了，得用 RDS（远程桌面服务）。两者的区别在于：RDS 是多人共享一台 Windows Server、各自独立会话，VDI 是每人一台独立虚拟桌面。

多人正式使用需要 RDP 用户授权，这也是带授权的方案价格直接跳到另一个量级的原因。GigeNET 的公开报价可以当价位参考：2 用户 $25/月（2 vCPU / 2GB / 20GB SSD / 5TB），4 用户 $50/月，8 用户 $120/月（8 vCPU / 16GB / 100GB / 10TB），所有方案都含 RDP 用户授权和 DDoS 防护。

算一下就很清楚：5 个人要各自一个账号，买 5 台单人 VPS 不但贵，还分散在 5 个地方没法统一管理；一台 8 用户 RDS 才 $120/月。反过来，只有你一个人用，买 RDS 就是浪费。
